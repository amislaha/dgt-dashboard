## Cross-cutting patterns (same root cause, multiple surfaces)

These aren't separate bugs — fixing the root once likely closes several numbered findings at once:

- **`--text-faint` fails WCAG AA almost everywhere it's used** — legacy launcher, legacy data-manager, legacy dashboard, legacy geomapping all define `--text-faint: #97a7b2`/`#71818c` and use it for real informational text (hints, meta, labels), computing to ~2.3–4.0:1 against their panels. See #3, #10, #23, #37, #48.
- **`--warn`/`gold` token fails contrast for text/icon use** — Angular dashboard (`ekonomi`/`geospasial` warn badges) and Angular geomapping (approval PENDING chip) both fail in light mode specifically (~2.75:1). See #44, #59.
- **Tap targets under 44×44px, systemically** — every surface has icon-only buttons in the 18–40px range used as primary controls (row actions, map toolbars, rail buttons). See #8, #21, #33, #56.
- **Custom interactive `<div>`s with click-only handlers, no keyboard path** — data-table rows, drawers/dialogs with no Escape handler, classification pickers, approval accordions, prov-tiles, rank-rows. See #29, #30, #35, #41, #58.

## Summary

**62 findings total**: 30 HIGH, 22 MEDIUM, 10 LOW.

The dominant failure modes are not "AI slop" in the classic decorative sense — both legacy tools in particular were called out by their auditors as unusually well-crafted (real content-driven layouts, no template/gradient/glassmorphism tells, honest fabricated-data handling per CLAUDE.md's documented conventions). The real exposure is:

1. **Accessibility (contrast + keyboard)** — the single biggest cluster. `--text-faint` and `--warn`/`gold` tokens fail WCAG AA in multiple places across multiple surfaces; several custom interactive elements (data-table rows, classification pickers, approval accordions, toggles) have no keyboard path at all.
2. **Mobile tap targets** — every surface has sub-44px icon buttons used as primary controls, most notably on the two field/tablet-oriented tools (data-manager, geomapping).
3. **One content-integrity issue that stands out from the rest**: #42, fabricated realistic Indonesian official names/credentials in the Angular dashboard's IKU data, attributed to a real government body. This is a different class of problem from the rest (R-23/R-38, not a cosmetic/a11y gap) and worth your attention regardless of what else you pick.
4. **A handful of genuinely dead controls** (#32-34, #24, #59) — small in number, cheap to fix.
