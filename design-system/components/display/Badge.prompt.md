Use `Badge` for record status and counts.

```jsx
<Badge tone="success" dot>Terverifikasi</Badge>
<Badge tone="warning" dot>Menunggu verifikasi</Badge>
<Badge tone="danger" dot>Ditolak</Badge>
```

Status mapping used across the kits: success = Terverifikasi/Selesai, warning = Menunggu/Proses, danger = Ditolak, info = Baru, neutral = Arsip.
